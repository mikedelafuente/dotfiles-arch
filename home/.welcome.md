## 🔑 Key Bindings

| Key | Action |
|-----|--------|
| `Tab` | Cycle through completions (menu-style) |
| `Shift+Tab` | Cycle backward through completions |
| `Up Arrow` | Search history backward (type prefix first!) |
| `Down Arrow` | Search history forward |
| `Ctrl+→` / `Alt+F` | Jump forward one word |
| `Ctrl+←` / `Alt+B` | Jump backward one word |
| `Ctrl+K` | Delete from cursor to end of line |
| `Ctrl+U` | Delete from cursor to start of line |
| `Ctrl+W` | Delete word backward |
| `Ctrl+A` | Go to beginning of line |
| `Ctrl+E` | Go to end of line |
| `Ctrl+R` | Fuzzy search command history (fzf) |
| `Ctrl+T` | Fuzzy pick a file into the command line (fzf) |
| `Alt+C` | Fuzzy cd into a subdirectory (fzf) |

> **Tip:** Editing keys live in `~/.inputrc`; `Ctrl+R`/`Ctrl+T`/`Alt+C` come from fzf.

## 🪟 Herdr Essentials

**Prefix Key:** `Ctrl+B` (press first, then command key)

### Quick Start
- `herdr` — Attach / create session
- `code [dir]` — New Herdr workspace with Neovim for a git repo
- `Ctrl+B` `q` — Detach (agents keep running)

### Most Used Commands
| Keys | Action |
|------|--------|
| `Ctrl+B` `v` | Split pane right |
| `Ctrl+B` `-` | Split pane down |
| `Ctrl+B` `c` | New tab |
| `Ctrl+B` `n/p` | Next / previous tab |
| `Ctrl+B` `?` | Show all keybindings |

> **Tip:** Run agents like `claude` inside panes — the sidebar shows working / blocked / done
