## 🪟 tmux Essentials

**Prefix Key:** `Ctrl+B` (press first, then command key)

### Quick Start
- `tmux attach` — Attach to a session (`tmux ls` to list)
- `code [dir]` — New tmux session: `code` window (Neovim + agent pane; focus starts on the agent), `console` window (shell in the project dir), optional `lazygit` for git repos
- `code [dir] --agent cursor|claude` — Same, but pick the agent explicitly
- `code [dir] --agent cursor --workspace NAME` — Cursor Agent with a saved CLI workspace
- `Ctrl+B` `d` — Detach (session keeps running)

### Most Used Commands
| Keys | Action |
|------|--------|
| `Ctrl+B` `%` | Split pane right |
| `Ctrl+B` `"` | Split pane down |
| `Ctrl+B` arrow keys | Focus pane left / down / up / right |
| `Ctrl+B` `c` | New window |
| `Ctrl+B` `n/p` | Next / previous window |
| `Ctrl+B` `?` | Show all keybindings |

> **Tip:** Run agents like `claude` inside panes; `Ctrl+B` `[` scrolls back through pane output
> **Tip:** `code --agent claude` bridges Neovim and Claude automatically (via `claudecode.nvim`) — `<leader>as` in Neovim sends a selection or file to the Claude pane and jumps focus there. See `config/nvim/README.md` for keybindings.
> **Tip:** Any file Claude or Cursor edits in a `code` session automatically opens (or reloads, if already open) in the Neovim pane — no manual `:e` needed.
