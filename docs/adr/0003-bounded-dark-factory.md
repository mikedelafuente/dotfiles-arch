# Bound factory delivery to approved workstation changes

Propose finite manual delivery using one parent GitHub issue with native sub-issues
and dependency links per approved change,
one integration branch, separate action authority, independent Standards/Spec
acceptance, and a hands-on prototype trial stop. Preserve the modular setup runner,
installed-generation boundary and existing Arch/Ubuntu architecture.

The human selected parent-issue grouping for future work. Historical milestone
selections remain unchanged. The resolver, budgets, guidance and action
policy remain proposals; no runtime adapter or unattended runner is established.
The simplest alternative is the existing interactive issue workflow. Choose it
while verifier, isolation, fencing or budget enforcement remain unavailable.

Private run records outlive worktrees; changes to their approved scope/policy create
hashed successors rather than rewriting active snapshots. Setup grants no tracker
publication, workstation mutation or scheduling permission. See
[setup index](../dark-factory/setup.json), [guidance](../dark-factory/guidance.md)
and [actual answers](../dark-factory/decisions.json).
